# GDP Per Capita Analysis

This project explores GDP per capita data from different international organisations, including the IMF, United Nations and World Bank.

The aim was to practise data cleaning, manipulation, analysis and visualisation using Python and Pandas, while investigating differences in GDP per capita across countries and regions.

## Dataset

The dataset contains GDP per capita estimates for countries and territories from different international organisations.

Some of the main variables include:

- Country/Territory
- UN Region
- IMF Estimate
- UN Estimate
- World Bank Estimate
- Year of each estimate

The original dataset is included in this repository.

## Analysis

In this project, I:

- explored and cleaned the dataset;
- checked missing and inconsistent values;
- examined the years available from each data source;
- compared mean and median GDP per capita;
- explored GDP distributions across countries and regions;
- identified countries at the upper and lower ends of the distributions;
- created visualisations to better understand the data.
